Cuenta simple — de lógica a objetos

Crea CuentaSimple desde cero. Calcula y consulta saldo primero en main, luego con método y finalmente con Cuenta. No es una aplicación bancaria real.

Preparación

JDK 21 e IDE o terminal; no requiere Maven ni JavaFX. Crea un proyecto autónomo. No reutilices una entrega de otro lab.

Lee Handbook de Academy si necesitas reforzar conceptos. La ejecución se realiza en tu equipo, no en el navegador.

1. Primer cálculo

Crea Main.java y ejecuta el cálculo de saldo; registra los valores y salida.

Configura y ejecuta

Crea un proyecto Java llamado CuentaSimple, con JDK 21. En IntelliJ, selecciona New Project → Java → JDK 21 → Create; crea Main.java dentro de src (marcado como Sources Root). También puedes usar un editor y la terminal.

public class Main {
    public static void main(String[] args) {
        double saldo = 10000;
        double deposito = 2500;
        double nuevoSaldo = saldo + deposito;
        System.out.println("Saldo inicial: " + saldo);
        System.out.println("Saldo final: " + nuevoSaldo);
    }
}

Ejecuta desde el IDE o, desde src, con javac Main.java y java Main. Debes ver 10000.0 y 12500.0. Predice el resultado si el depósito es 1000, compruébalo (11000.0) y restaura 2500. Si no aparece Run, revisa SDK y Sources Root; si la terminal no reconoce javac, comprueba javac -version.

2. Método reutilizable

Extrae el cálculo a un método con parámetros y retorno; comprueba el mismo resultado.

Extrae la responsabilidad de calcular

public class Main {
    public static void main(String[] args) {
        System.out.println("Saldo final: " + calcularSaldo(10000, 2500));
        System.out.println("Otro saldo: " + calcularSaldo(4000, 500));
    }
    public static double calcularSaldo(double saldo, double deposito) {
        return saldo + deposito;
    }
}

Reemplaza Main.java y ejecuta nuevamente: 12500.0 y 4500.0. Identifica parámetros, argumentos y retorno. Si el compilador no encuentra el método, comprueba nombre, firma y que esté dentro de la clase pero fuera de main. Un método estático reutiliza el cálculo, pero no conserva el saldo de una cuenta.

3. Clase Cuenta

Crea Cuenta.java, construye dos objetos y consulta saldos independientes.

Modela estado y comportamiento

Crea Cuenta.java junto a Main.java.

public class Cuenta {
    private final String titular;
    private double saldo;
    public Cuenta(String titular, double saldoInicial) {
        this.titular = titular;
        this.saldo = saldoInicial;
    }
    public void depositar(double monto) { saldo += monto; }
    public double getSaldo() { return saldo; }
    public String getTitular() { return titular; }
}

Reemplaza Main.java:

public class Main {
    public static void main(String[] args) {
        Cuenta ana = new Cuenta("Ana", 10000);
        Cuenta pedro = new Cuenta("Pedro", 4000);
        ana.depositar(2500);
        pedro.depositar(500);
        System.out.println(ana.getTitular() + ": " + ana.getSaldo());
        System.out.println(pedro.getTitular() + ": " + pedro.getSaldo());
    }
}

Desde src ejecuta javac Main.java Cuenta.java y java Main. Esperado: Ana: 12500.0 y Pedro: 4500.0. Si no compila, comprueba que ambos archivos estén en la misma carpeta y que el nombre de cada clase pública coincida con el archivo. Explica por qué saldo no debe ser static. Se usa double solo para simplificar el ejercicio, no para modelar dinero real; la validación de depósitos queda fuera de este alcance.

4. Pruebas y explicación

Compara salidas esperadas con observadas; explica método, argumentos y estado propio.

Comprueba independencia del estado

Agrega ana.depositar(1000); después del primer depósito de Ana. Compila y ejecuta. Compara los tres casos y luego restaura la versión del paso anterior.

  • T01: Ana deposita 2500 → 12500.0.
  • T02: Pedro deposita 500 → 4500.0.
  • T03: segundo depósito de Ana de 1000 → 13500.0; Pedro conserva 4500.0.

Si ambos saldos cambian al depositar en una sola cuenta, revisa que saldo sea un atributo de instancia y no static.
