1. Tipos y capacidades

Identifica qué es Equipo y qué representa una capacidad.

Paso 1 · Crear el entorno desde cero

  1. Abre IntelliJ IDEA → File → New → Project.
  2. Selecciona Java, nombre SoporteTecnico, JDK 21 y Build system IntelliJ.
  3. Pulsa Create, espera el indexado y abre el panel Project.
  4. Sobre la carpeta src, clic derecho → New → Java Class → Main.
  5. Pega:
public class Main {
    public static void main(String[] args) {
        System.out.println("Centro de soporte iniciado");
    }
}
  1. Pulsa el triángulo verde junto a main.

Checkpoint A: consola muestra Centro de soporte iniciado. Si falla, comprueba el JDK del proyecto y marca src como Sources Root.

Paso 2 · Pensar antes de programar

Anota los objetos del caso: Computador e Impresora. Ambos comparten el código y la necesidad de describirse; solo el computador puede recibir una actualización de software.

  • «ES UN Equipo» se modela por herencia.
  • «PUEDE actualizar software» se modela mediante una interfaz.

Checkpoint B: puedes explicar por qué no obligaremos a la impresora a implementar la actualización de software del computador.

2. Clase abstracta

Construye Equipo abstracto y subtipos con descripción propia.

Paso 1 · Crear Equipo.java

En src, clic derecho → New → Java Class → Equipo. Reemplaza el contenido:

public abstract class Equipo {
    private final String codigo;

    public Equipo(String codigo) {
        this.codigo = codigo;
    }

    public String getCodigo() { return codigo; }

    public abstract String descripcion();
}

Checkpoint A: Equipo es abstracta y declara un método sin implementación. Por ello, new Equipo("E01") no está permitido. No agregues esa línea inválida al programa final.

Paso 2 · Crear Impresora.java

Clic derecho en src → New → Java Class → Impresora. Copia:

public class Impresora extends Equipo {
    private final String tecnologia;

    public Impresora(String codigo, String tecnologia) {
        super(codigo);
        this.tecnologia = tecnologia;
    }

    @Override public String descripcion() {
        return "Impresora " + getCodigo() + " / " + tecnologia;
    }
}

Checkpoint B: identifica extends, super(codigo) y @Override.

Paso 3 · Probar el primer subtipo

Reemplaza temporalmente Main.java:

public class Main {
    public static void main(String[] args) {
        Equipo equipo = new Impresora("IMP01", "Láser");
        System.out.println(equipo.descripcion());
    }
}

Ejecuta. Debe mostrar Impresora IMP01 / Láser.

Checkpoint C: una variable de tipo Equipo puede apuntar a una Impresora concreta.

Checkpoint: registra el resultado indicado antes de continuar.

3. Interfaz Actualizable

Implementa la capacidad solo en Computador.

Paso 1 · Crear la interfaz

En src, clic derecho → New → Java Class y selecciona el tipo Interface; nómbrala Actualizable. Pega:

public interface Actualizable {
    String actualizarSoftware();
}

Checkpoint A: expresa una capacidad. No contiene atributos de equipo ni una jerarquía.

Paso 2 · Crear Computador.java

Sobre src, clic derecho → New → Java Class → Computador. Pega:

public class Computador extends Equipo implements Actualizable {
    private final int ramGb;

    public Computador(String codigo, int ramGb) {
        super(codigo);
        this.ramGb = ramGb;
    }

    @Override public String descripcion() {
        return "Computador " + getCodigo() + " / RAM " + ramGb + " GB";
    }

    @Override public String actualizarSoftware() {
        return "Actualización preparada para " + getCodigo();
    }
}

Checkpoint B: Computador usa extends Equipo e implements Actualizable. El @Override de descripcion responde al método abstracto; el de actualizarSoftware responde a la interfaz.

Paso 3 · Ejecutar

En Main.java, escribe:

public class Main {
    public static void main(String[] args) {
        Computador pc = new Computador("PC01", 16);
        System.out.println(pc.descripcion());
        System.out.println(pc.actualizarSoftware());
    }
}

Ejecuta. Aparecen Computador PC01 / RAM 16 GB y Actualización preparada para PC01.

Checkpoint C: Impresora sigue compilando sin implementar Actualizable: la interfaz no es una exigencia para todos los Equipo.

4. Integrar

Demuestra descripción polimórfica y actualización únicamente del tipo compatible.

Paso 1 · Integrar ambas clases en Main

Abre src/Main.java, reemplaza:

public class Main {
    public static void main(String[] args) {
        Equipo[] equipos = {
            new Impresora("IMP01", "Láser"),
            new Computador("PC01", 16),
            new Impresora("IMP02", "Inyección")
        };

        for (Equipo equipo : equipos) {
            System.out.println(equipo.descripcion());
            if (equipo instanceof Actualizable actualizable) {
                System.out.println("  " + actualizable.actualizarSoftware());
            } else {
                System.out.println("  No requiere actualización de software");
            }
        }
    }
}

Pulsa Run.

Checkpoint A: se imprimen tres descripciones y una sola actualización, asociada al computador.
