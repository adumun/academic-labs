Incremento 01 · 15 min

Configurar entorno y conexión

Crea un proyecto Maven Java 21. Instala y arranca MariaDB; crea capsula_db y una cuenta local limitada a SELECT, INSERT, UPDATE y DELETE. Configura DB_USER y DB_PASSWORD en IntelliJ. Prueba la conexión antes de incorporar GUI.

Ayuda 1 · Concepto

JDBC es una API; el driver implementa la comunicación con el servidor.

Ayuda 2 · Pista técnica

Agrega MariaDB Connector/J 3.5.11 al pom y prueba DriverManager. Revisa host, puerto y credenciales si falla.

Ayuda 3 · Fragmento y referencia
try (Connection con = DriverManager.getConnection("jdbc:mariadb://localhost:3306/capsula_db", System.getenv("DB_USER"), System.getenv("DB_PASSWORD"))) {
    System.out.println("Conexión exitosa");
}

Guía y fuentes canónicas

Resultado esperado

Conexión exitosa; verifica el servidor y la base por separado.

Incremento 02 · 15 min

Modelo y SQL

Crea tabla capsula con id autoincremental, titulo VARCHAR(100), mensaje TEXT, fecha_apertura DATE, todos los campos de negocio obligatorios. Inserta dos registros de prueba. Crea clase Capsula con constructor y getters.

Ayuda 1 · Concepto

Un objeto no es una fila: el modelo representa el dominio.

Ayuda 2 · Pista técnica

Mapea INT a int, VARCHAR/TEXT a String y DATE a LocalDate.

Ayuda 3 · Fragmento y referencia
SELECT id, titulo, mensaje, fecha_apertura FROM capsula ORDER BY id;

Guía y fuentes canónicas

Resultado esperado

SELECT muestra dos filas; el modelo contiene los cuatro atributos.

Incremento 03 · 15 min

ResultSet y mapeo

Implementa una lectura que construya una List<Capsula>. Cierra todos los recursos automáticamente. Prueba con cero, una y dos filas.

Ayuda 1 · Concepto

El cursor comienza antes de la primera fila.

Ayuda 2 · Pista técnica

Usa while(rs.next()), getters por nombre de columna y constructor.

Ayuda 3 · Fragmento y referencia
while (rs.next()) {
    lista.add(new Capsula(rs.getInt("id"), rs.getString("titulo"), rs.getString("mensaje"), rs.getDate("fecha_apertura").toLocalDate()));
}

Guía y fuentes canónicas

Resultado esperado

La cantidad de objetos coincide con la cantidad de registros.

Incremento 04 · 20 min

PreparedStatement y CRUD

Implementa insertar, actualizar y eliminar. Identifica registros por id y usa parámetros para todos los valores. Prueba texto con apóstrofo y un id inexistente.

Ayuda 1 · Concepto

Los parámetros separan instrucciones SQL de datos.

Ayuda 2 · Pista técnica

Usa executeUpdate para cambios y executeQuery para lectura. Los índices comienzan en 1.

Ayuda 3 · Fragmento y referencia
try (PreparedStatement ps = con.prepareStatement("DELETE FROM capsula WHERE id = ?")) {
    ps.setInt(1, id);
    int filas = ps.executeUpdate();
}

Guía y fuentes canónicas

Resultado esperado

Inserción, actualización y eliminación verificadas en SQL; registros ajenos intactos.
