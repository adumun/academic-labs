1. Primer objeto

Crea proyecto nuevo e instancia Inscripcion.

Paso 1 · Iniciar el proyecto

  1. Abre IntelliJ IDEA → New Project o File → New → Project.
  2. Selecciona Java en el panel izquierdo.
  3. Escribe RegistroTalleres como nombre, selecciona JDK 21 y Build system: IntelliJ.
  4. Pulsa Create, espera que termine la indexación y localiza src en el panel Project.
  5. Clic derecho sobre src → New → Java Class → Main.

Pega en Main.java:

public class Main {
    public static void main(String[] args) {
        System.out.println("Registro de talleres iniciado");
    }
}

Presiona el triángulo verde junto al método main.

Checkpoint A: la consola muestra Registro de talleres iniciado. Si no existe src, crea esa carpeta y márcala como Sources Root; si no corre, revisa JDK en File → Project Structure → Project.

Paso 2 · Crear el dato Inscripcion

  1. Clic derecho en src → New → Java Class → Inscripcion.
  2. Reemplaza todo por:
public class Inscripcion {
    private final String persona;
    private final String taller;

    public Inscripcion(String persona, String taller) {
        this.persona = persona;
        this.taller = taller;
    }

    public String getPersona() { return persona; }
    public String getTaller() { return taller; }

    public String resumen() { return persona + " → " + taller; }
}

Checkpoint B: existen src/Main.java y src/Inscripcion.java. Inscripcion representa una inscripción, no un conjunto de inscripciones. ¿Quién debería almacenar muchas? La etapa siguiente responderá eso.

2. Array

Guarda varias inscripciones y demuestra el límite de longitud.

Paso 1 · Sustituir Main

Abre src/Main.java, presiona Ctrl+A y escribe:

public class Main {
    public static void main(String[] args) {
        Inscripcion[] cupos = new Inscripcion[3];
        cupos[0] = new Inscripcion("Ana", "Pintura");
        cupos[1] = new Inscripcion("Pedro", "Música");
        cupos[2] = new Inscripcion("Rosa", "Pintura");

        for (int i = 0; i < cupos.length; i++) {
            System.out.println((i + 1) + ". " + cupos[i].resumen());
        }
    }
}

Pulsa Run y revisa que aparecen tres líneas.

Checkpoint A: sabes por qué el array reserva 3 posiciones y por qué su índice inicial es cero.

Paso 2 · Descubrir un límite

  1. Agrega temporalmente una cuarta línea: cupos[3] = new Inscripcion("Luis", "Teatro");.
  2. Ejecuta otra vez y lee el mensaje de error.
  3. Observa ArrayIndexOutOfBoundsException: la cuarta posición no existe porque el tamaño es fijo.
  4. Elimina la línea de prueba para recuperar el programa funcional.

Checkpoint B: el programa vuelve a imprimir tres líneas. Escribe en tu evidencia: «un array tiene tamaño fijo; necesitaré otra estructura para altas variables».

Paso 3 · Discutir responsabilidad

El código de Main crea y administra directamente las posiciones. En la siguiente etapa crearemos un RegistroTaller que concentre esa responsabilidad y utilice una List. Así evitamos que Main haga todo.

3. Lista dinámica

Evoluciona a List/ArrayList; registra, recorre, busca y elimina.

Paso 1 · Crear la clase administradora

  1. En src, clic derecho → New → Java Class → RegistroTaller.
  2. Pega el código:
import java.util.ArrayList;
import java.util.List;

public class RegistroTaller {
    private final List<Inscripcion> inscripciones = new ArrayList<>();

    public void agregar(Inscripcion nueva) {
        inscripciones.add(nueva);
    }

    public Inscripcion buscar(String persona) {
        for (Inscripcion i : inscripciones) {
            if (i.getPersona().equalsIgnoreCase(persona)) return i;
        }
        return null;
    }

    public boolean eliminar(String persona) {
        return inscripciones.removeIf(
                i -> i.getPersona().equalsIgnoreCase(persona));
    }

    public void mostrar() {
        for (Inscripcion i : inscripciones) {
            System.out.println(i.resumen());
        }
    }

    public int cantidad() { return inscripciones.size(); }
}

Checkpoint A: identifica la declaración List<Inscripcion> y la creación new ArrayList<>(). La lista puede crecer sin definir cupos máximos de antemano.

Paso 2 · Reemplazar Main

Abre Main.java y reemplaza el contenido por:

public class Main {
    public static void main(String[] args) {
        RegistroTaller registro = new RegistroTaller();

        registro.agregar(new Inscripcion("Ana", "Pintura"));
        registro.agregar(new Inscripcion("Pedro", "Música"));
        registro.agregar(new Inscripcion("Rosa", "Pintura"));
        registro.agregar(new Inscripcion("Luis", "Teatro"));

        registro.mostrar();
        System.out.println("Total: " + registro.cantidad());
        System.out.println("Buscar Pedro: " + registro.buscar("Pedro").resumen());

        registro.eliminar("Rosa");
        System.out.println("Total tras eliminar: " + registro.cantidad());
    }
}

Pulsa Run: el total inicial debe ser 4 y el posterior 3.

Checkpoint B: la cuarta inscripción funciona sin cambiar una constante de tamaño. El método buscar devuelve null cuando no encuentra; no llames .resumen() sobre un null (causaría NullPointerException).

Paso 3 · Preguntas

¿Por qué Main dejó de manipular índices? ¿Qué responsabilidad tiene RegistroTaller? Explica la diferencia entre tipo List e implementación ArrayList.

4. Errores y pruebas

Rechaza duplicados y registra evidencia de alta válida y fallo controlado.

Paso 1 · Incorporar reglas al registro

Abre RegistroTaller.java. Reemplaza solamente el método agregar(Inscripcion nueva) por:

public void agregar(Inscripcion nueva) {
    if (nueva == null ||
        nueva.getPersona() == null || nueva.getPersona().isBlank() ||
        nueva.getTaller() == null || nueva.getTaller().isBlank()) {
        throw new IllegalArgumentException("Persona y taller son obligatorios");
    }
    if (buscar(nueva.getPersona()) != null) {
        throw new IllegalArgumentException("La persona ya está inscrita");
    }
    inscripciones.add(nueva);
}

La regla del ejercicio es una inscripción por persona. Si quisieras permitir inscripciones en varios talleres, tendrías que redefinir esa regla; no la cambies durante esta prueba.

Checkpoint A: el resto de la clase permanece igual. throw comunica un dato inválido; no es equivalente a System.out.println.

Paso 2 · Probar el error sin cerrar el programa

En Main.java, después de agregar los cuatro registros y antes de imprimir el total, inserta:

try {
    registro.agregar(new Inscripcion("Ana", "Teatro"));
} catch (IllegalArgumentException error) {
    System.out.println("Error controlado: " + error.getMessage());
}

Ejecuta y verifica el mensaje Error controlado: La persona ya está inscrita. El resto del programa debe seguir y mostrar los totales 4 y 3.
