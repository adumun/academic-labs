Instrucciones y entrega

Completa solución, respuesta y evidencia de prueba. Confirma y avanza, o salta y vuelve después. Los datos se mantienen al navegar dentro de esta página; recargar puede perderlos. Descarga avances parciales cuando quieras. No se envían datos a servidores.

Entorno y código base

Java 21, Maven, MariaDB local, JavaFX cuando corresponda. Trabaja en una base desechable, con usuario limitado. Los fragmentos requieren un contexto de clase compatible y no son programas completos.
