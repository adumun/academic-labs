Microdesafíos JDBC y JavaFX

Ocho retos independientes de 15 a 25 minutos. Selecciona los que correspondan a tus brechas.

Tu avance

La evidencia permanece en esta página hasta exportarla; recargar puede perderla. No se envían datos. Los fragmentos se ejecutan localmente, no en el navegador.

Entorno y código base

Java 21, Maven, MariaDB local, JavaFX cuando corresponda. Trabaja en una base desechable, con usuario limitado. Los fragmentos requieren un contexto de clase compatible y no son programas completos.

Esquema, modelo Libro y proyecto de arranque

15 min · Diagnosticar conexión JDBC

1. Conexión fallida

Configura un acceso a la base local de práctica. La URL inicial contiene un puerto incorrecto. Identifica la causa sin imprimir la contraseña.

Prueba: Conexión exitosa con la configuración correcta; un puerto incorrecto produce un diagnóstico comprensible.

Fuente canónica
15 min · PreparedStatement

2. Consulta insegura

Reemplaza la construcción de SQL con concatenación. Busca por título exacto.

Prueba: El título O'Connor se recupera como dato literal; no se concatena la entrada.

Fuente canónica
20 min · ResultSet y mapeo

3. De filas a objetos

Completa el método que devuelve una lista de Libro. El cursor comienza antes de la primera fila.

Prueba: Con cero filas devuelve una lista vacía; con dos filas devuelve dos objetos correctos.

Fuente canónica
20 min · CRUD por clave primaria

4. ¿Dónde está mi registro?

Completa una actualización y eliminación por ID usando parámetros. Verifica filas afectadas.

Prueba: Editar ID existente modifica solo su fila; ID inexistente produce cero filas afectadas.

Fuente canónica
25 min · Separación MVC y DAO

5. Un controlador desordenado

Extrae el acceso SQL de un controlador y define un contrato LibroDao. El controlador debe depender de dicho contrato.

Prueba: El controlador no contiene SQL; DAO no importa JavaFX; listado funciona igual.

Fuente canónica
20 min · FXML, TableView y refresco

6. Mi TableView está vacía

Vincula la columna al getter correcto, carga registros desde DAO y refresca después de una modificación.

Prueba: Dos registros visibles; después de guardar un tercero la tabla refleja SQL.

Fuente canónica
20 min · Validación y excepciones

7. Formulario defectuoso

Rechaza título vacío, mayor de 120 caracteres y selección nula al editar. No pierdas entradas inválidas.

Prueba: No se llama al DAO con datos inválidos; aparece un mensaje claro.

Fuente canónica
15 min · Verificación de persistencia

8. Los datos desaparecieron

Guarda un libro único, reinicia la aplicación y compara el listado con SQL. Distingue memoria de base de datos.

Prueba: El mismo ID y título aparecen después de reiniciar.
