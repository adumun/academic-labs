Detective JDBC

Investiga ocho casos seleccionados de un banco de 24 preguntas. No se ejecuta código ni se necesita una base de datos.

Reglas del intento

Una pregunta por pantalla, sin retroceder. Selección simple: 35 s; selección múltiple: 50 s; verdadero/falso: 20 s. El reloj sigue corriendo al cambiar de pestaña o recargar. Recargar deliberadamente para obtener otra pregunta constituye trampa; una recarga accidental queda registrada como incidencia, no prueba de fraude.

Responde sin asistencia externa. Cada intento incluye los tres tipos de pregunta, con dos o tres de cada tipo. Las preguntas y alternativas se mezclan. Si abandonas el desafío, los plazos de los casos siguientes también pueden agotarse mientras estás fuera. El intento se conserva en este navegador; no hay servidor, vigilancia ni garantía de identidad. No borres los datos del sitio para reiniciar. No se muestran soluciones durante el desafío.

Investigación finalizada

El resultado es formativo. No acredita identidad, ausencia de ayuda externa ni integridad del intento.
