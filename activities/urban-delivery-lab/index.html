Despachos urbanos — herencia y polimorfismo

Crea DespachosUrbanos. Envío normal = $1.000 + $500 por kilómetro; expreso añade $2.000. Clases Envio, EnvioExpress y Main; sin arrays ni interfaces requeridas.

Preparación

JDK 21 e IDE o terminal; no requiere Maven ni JavaFX. Crea un proyecto autónomo. No reutilices una entrega de otro lab.

Lee Handbook de Academy si necesitas reforzar conceptos. La ejecución se realiza en tu equipo, no en el navegador.

1. Entorno

Crea y ejecuta proyecto Java nuevo.

Punto de partida

Necesitas IntelliJ IDEA y JDK 21 configurado. No abras ningún laboratorio anterior.

Paso 1 · Crear el proyecto

  1. Abre IntelliJ IDEA.
  2. En la pantalla inicial elige New Project (si ya estás dentro, File → New → Project).
  3. En la columna izquierda selecciona Java, no JavaFX.
  4. Escribe DespachosUrbanos en Name, selecciona JDK 21 y Build system: IntelliJ. Si tu IDE propone código de muestra, puedes desmarcarlo.
  5. Pulsa Create; espera hasta que termine de indexar.
  6. Abre el panel Project y localiza src. Si no existe, clic derecho sobre la raíz → New → Directory → src; clic derecho en src → Mark Directory as → Sources Root.

Checkpoint A: existe una carpeta de código src donde crearás las clases.

Paso 2 · Crear Main.java

  1. Clic derecho en src → New → Java Class → escribe Main.
  2. Reemplaza el código con:
public class Main {
    public static void main(String[] args) {
        System.out.println("Despachos urbanos: listo para comenzar");
    }
}
  1. Guarda (Ctrl+S) y pulsa el triángulo verde junto a main → Run 'Main.main()'.

Checkpoint B: la consola muestra exactamente Despachos urbanos: listo para comenzar y termina sin errores. Si no ves el triángulo, verifica que Main.java está dentro de src y que el SDK del proyecto es 21.

2. Clase base y subclase

Usa extends, super y Override; 3 km normal 2500, expreso 4500.

Paso 1 · Crear la clase padre

  1. Clic derecho sobre src → New → Java Class → Envio.
  2. Pega el archivo completo:
public class Envio {
    private final String codigo;
    private final int distanciaKm;

    public Envio(String codigo, int distanciaKm) {
        this.codigo = codigo;
        this.distanciaKm = distanciaKm;
    }

    public String getCodigo() { return codigo; }
    public int getDistanciaKm() { return distanciaKm; }

    public int calcularCosto() {
        return 1000 + (500 * distanciaKm);
    }
}

Checkpoint A: no hay errores de sintaxis. Señala cuál método devuelve el costo base para todo envío.

Paso 2 · Crear la subclase

  1. Clic derecho en src → New → Java Class → EnvioExpress.
  2. Copia el archivo entero:
public class EnvioExpress extends Envio {
    public EnvioExpress(String codigo, int distanciaKm) {
        super(codigo, distanciaKm);
    }

    @Override
    public int calcularCosto() {
        return super.calcularCosto() + 2000;
    }
}

¿Qué acaba de pasar? extends Envio evita duplicar los atributos. super(codigo, distanciaKm) ejecuta el constructor del padre. super.calcularCosto() reutiliza la tarifa base; @Override confirma que estamos redefiniendo un método existente.

Paso 3 · Comprobar el cálculo

En Main.java, reemplaza el contenido con:

public class Main {
    public static void main(String[] args) {
        Envio normal = new Envio("N01", 3);
        EnvioExpress rapido = new EnvioExpress("E01", 3);

        System.out.println("Normal: " + normal.calcularCosto());
        System.out.println("Expreso: " + rapido.calcularCosto());
    }
}

Ejecuta Main.main() otra vez.

Checkpoint B: consola: Normal: 2500 y Expreso: 4500. Si ambos salen iguales, revisa la firma del método y que EnvioExpress tenga @Override. Si faltan clases, comprueba que los tres archivos están en la misma carpeta de código.

3. Referencia base

Invoca ambos comportamientos mediante variables Envio.

Paso 1 · Cambiar solo Main

  1. Abre src/Main.java.
  2. Reemplaza su contenido:
public class Main {
    public static void main(String[] args) {
        Envio primero = new Envio("N01", 3);
        Envio segundo = new EnvioExpress("E01", 3);

        mostrar(primero);
        mostrar(segundo);
    }

    private static void mostrar(Envio envio) {
        System.out.println(envio.getCodigo() + ": $" + envio.calcularCosto());
    }
}
  1. Pulsa Run.

Checkpoint A: obtienes N01: $2500 y E01: $4500.

Paso 2 · Explicar sin copiar

El parámetro del método mostrar es Envio; acepta tanto Envio como EnvioExpress. Java elige el método sobrescrito según el tipo real del objeto.

Responde en tu evidencia:

  1. ¿Por qué mostrar(Envio) no tiene un if que pregunte por el tipo?
  2. ¿Qué cambia si quitas @Override y escribes mal el nombre del método?
  3. ¿En qué se diferencian super() y super.calcularCosto()?

Paso 3 · Mini desafío guiado

Cambia la distancia de E01 de 3 a 5 kilómetros. Calcula a mano el resultado antes de ejecutar: $1.000 + $2.500 + $2.000 = $5.500. Ejecuta y compara.

Checkpoint B: explicas cómo se reutiliza el código común y por qué una referencia Envio llama al cálculo expreso. No necesitamos arreglos ni colecciones para demostrarlo.
