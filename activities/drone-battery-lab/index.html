Batería de un dron — encapsulamiento

Crea BateriaDron. Bateria mantiene porcentaje 0–100; cargar y consumir no deben salir del rango. Dos dispositivos poseen estados independientes. Sin colecciones, JavaFX ni excepciones requeridas.

Preparación

JDK 21 e IDE o terminal; no requiere Maven ni JavaFX. Crea un proyecto autónomo. No reutilices una entrega de otro lab.

Lee Handbook de Academy si necesitas reforzar conceptos. La ejecución se realiza en tu equipo, no en el navegador.

2. Modelo de batería

Crea Bateria con constructor, estado privado y consulta.

Paso 1 · Implementar Bateria.java

Abre src/Bateria.java. Reemplaza su contenido:

public class Bateria {
    private final String dispositivo;
    private int porcentaje;

    public Bateria(String dispositivo) {
        this.dispositivo = dispositivo;
        this.porcentaje = 0; // Batería nueva: descargada
    }

    public String getDispositivo() { return dispositivo; }
    public int getPorcentaje() { return porcentaje; }
}

Checkpoint A: identifica dos atributos privados, un constructor y getters. No hay un setter que permita porcentaje = 300.

Paso 2 · Crear dos objetos

En Main.java, reemplaza por:

public class Main {
    public static void main(String[] args) {
        Bateria dron = new Bateria("Dron");
        Bateria camara = new Bateria("Cámara");

        System.out.println(dron.getDispositivo() + ": " + dron.getPorcentaje() + "%");
        System.out.println(camara.getDispositivo() + ": " + camara.getPorcentaje() + "%");
    }
}

Ejecuta. La consola muestra dos baterías distintas al 0%.

Checkpoint B: cada objeto mantiene estado propio. El constructor establece un valor inicial válido sin recibir un porcentaje arbitrario.

Paso 3 · ¿Dónde debería cambiar el porcentaje?

No cambies dron.porcentaje desde Main: es privado. La propia clase Bateria debe decidir si una operación es válida. La etapa siguiente añade métodos con esas reglas.

3. Proteger el porcentaje

Implementa operaciones con retorno boolean; rechaza cambios inválidos sin modificar el estado.

Paso 1 · Agregar métodos dentro de Bateria

Abre src/Bateria.java. No borres el constructor ni los getters. Inserta estos dos métodos antes de la última llave } de la clase:

public boolean cargar(int puntos) {
    if (puntos <= 0 || porcentaje + puntos > 100) {
        return false;
    }
    porcentaje += puntos;
    return true;
}

public boolean consumir(int puntos) {
    if (puntos <= 0 || puntos > porcentaje) {
        return false;
    }
    porcentaje -= puntos;
    return true;
}

Checkpoint A: ambos métodos compilan. Si agregas las llaves fuera de la clase, IntelliJ marcará error rojo: verifica que estén dentro de Bateria.

Paso 2 · Ejecutar acciones desde Main

En Main.java, después de crear ambos objetos y antes de la llave final de main, agrega:

System.out.println("Carga dron: " + dron.cargar(60));
System.out.println("Carga cámara: " + camara.cargar(30));
System.out.println("Consumo dron: " + dron.consumir(20));
System.out.println("Consumo imposible cámara: " + camara.consumir(40));
System.out.println("Dron final: " + dron.getPorcentaje() + "%");
System.out.println("Cámara final: " + camara.getPorcentaje() + "%");

Ejecuta. Los retornos son true, true, true, false. El dron queda en 40% y la cámara en 30%.

Checkpoint B: la cámara no baja de 0 aunque intentes consumir más de lo disponible.

Paso 3 · Entender responsabilidades

Main solicita acciones; Bateria protege sus propias reglas. El retorno false expresa operación rechazada sin introducir todavía excepciones.

4. Pruebas

Comprueba límites 0 y 100 y estados de dos dispositivos.

Paso 1 · Ejecutar pruebas

Conserva Main de etapa 03 y añade después de sus operaciones:

System.out.println("Sobrecarga dron: " + dron.cargar(70));
System.out.println("Consumo imposible dron: " + dron.consumir(50));
System.out.println("Carga adicional cámara: " + camara.cargar(20));
System.out.println("Dron: " + dron.getPorcentaje() + "%");
System.out.println("Cámara: " + camara.getPorcentaje() + "%");

Checkpoint A: aparecen false, false, true; el dron sigue en 40% y la cámara llega a 50%.
